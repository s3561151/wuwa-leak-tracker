鳴潮情報追蹤站 v1

部署：建議將此資料夾上傳 GitHub 儲存庫，再在 Netlify 以該儲存庫建立新網站並部署。請勿覆蓋漫畫轉檔網站。

重要限制：
1. 已有每天台灣時間 08:00 的 Netlify 排程函式，只有成功部署且 Functions 正常運作才會啟動。
2. 目前僅實作 Reddit 單一公開來源的貼文標題與連結抓取，並非多平台全面蒐集。Reddit 可能限制或拒絕伺服器存取；需實測。
3. 尚未實作自動繁體中文翻譯：畫面優先顯示中文欄位，未有翻譯時顯示原文。後續需接入翻譯 API，避免將 API 金鑰暴露於網頁。
4. 尚未實作跨貼文語義去重、可信度評估、版本自動判定、推播。
5. 資料儲存使用 Netlify Blobs。需確認網站 Functions、Blobs 支援和部署流程。直接拖曳 ZIP 到 Netlify Drop 可能無法正確建置伺服器函式，建議 Git 部署。
6. 在第一次排程成功前，情報清單可能是空的。可在 Netlify Functions 頁面對 daily-sync 選擇 Run now 進行測試。
7. Reddit 貼文屬未經證實傳聞；不得視為官方資訊。
